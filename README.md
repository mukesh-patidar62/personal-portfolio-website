# Mukesh Patidar Personal Portfolio

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, or use VS Code Live Server.
3. Replace placeholder GitHub, LinkedIn and email links in `index.html`.
4. Replace the placeholder second/third project details with your actual projects.
5. Add your resume as `resume.pdf` and change the resume button/link if desired.

No build tools or npm are required.
